# 補給車1台固定・新補給方式版

補給車を1台固定にし、残りのエージェントを巡回車にする比較用プロジェクトです。最寄りスポットまでのA*の必要step数が少ない順に巡回車へ割り当てます。

補給対象は新方式（停止車の救出・燃料不足の予防・補給効果の比較・補給直後の追従抑制）を使用します。その他の巡回経路・同期・GUIは新方式版と同じです。

GUIへの参加は [gui/README.md](gui/README.md)、新方式の説明と台数変更前の比較結果は [COMPARISON.md](COMPARISON.md) を参照してください。COMPARISON.md内の表は補給車1台固定版の成績ではありません。
